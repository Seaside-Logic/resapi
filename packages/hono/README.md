# @resapi/hono

[Hono](https://hono.dev) server adapter for [resAPI](https://github.com/seasidelogic/resapi) contracts. Runs on Node and Cloudflare Workers.

```sh
npm install @resapi/core @resapi/hono hono
```

Add `"@resapi/core"` and `"@resapi/hono"` to `dependencies` in `rescript.json`. Modules are under the `ResApiHono` namespace. Tested with Hono 4.13.

See the [README](https://github.com/seasidelogic/resapi#readme) and [API reference](https://github.com/seasidelogic/resapi/blob/main/docs/api.md).
