# @resapi/core

Type-safe HTTP contracts for ReScript: endpoint contracts, codecs and a typed client. Part of [resAPI](https://github.com/seasidelogic/resapi).

```sh
npm install @resapi/core
```

Add `"@resapi/core"` to `dependencies` in `rescript.json`. Modules are under the `ResApi` namespace.

See the [README](https://github.com/seasidelogic/resapi#readme) and [API reference](https://github.com/seasidelogic/resapi/blob/main/docs/api.md).
